# Sécurité / Security

## Signaler une faille (FR)
PCDoc fonctionne avec les droits administrateur : une faille peut être grave.
**Ne publiez pas de ticket public.** Utilisez le signalement privé de GitHub :
onglet *Security* du dépôt → *Report a vulnerability*.

Nous visons une première réponse sous **7 jours**. Merci d'indiquer la version de PCDoc,
la version de Windows et les étapes pour reproduire le problème.

## Reporting a vulnerability (EN)
PCDoc runs with administrator rights, so vulnerabilities can be serious.
**Do not open a public issue.** Use GitHub private reporting:
repository *Security* tab → *Report a vulnerability*.

We aim to reply within **7 days**. Please include the PCDoc version, the Windows version
and the steps to reproduce.

## Versions prises en charge / Supported versions
Seule la dernière version publiée reçoit des correctifs. / Only the latest release receives fixes.
