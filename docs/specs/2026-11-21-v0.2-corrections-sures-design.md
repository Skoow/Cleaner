# v0.2 — Corrections sûres (design court)

Découpage décidé : la v0.2 rend le bouton « Corriger » sûr ; le Diagnostic (M3) passe en v0.3 et le reste de la feuille de route recule d'un cran.

## Contenu
1. **Niveaux de risque** (spec v2 §5) : `RiskLevel { Safe 🟢, Conditional 🟠, Discouraged 🔴, Locked 🔒 }` remplace `FixRisk`.
2. **Modes** : `AppMode { Novice, Expert }` dans les paramètres (défaut Novice) + `FirstRunCompleted`.
   - Novice : seules les corrections 🟢 sont proposées (une 🟠 dont la condition est vérifiée devient 🟢) ; 🔴 masquées.
   - Expert : 🟢 🟠 🔴 proposées ; 🔴 une par une avec confirmation renforcée. 🔒 jamais.
   - « Tout corriger » = 🟢 uniquement, dans les deux modes.
3. **Pipeline de correction** (`FixPipeline`, Core) : point de restauration une fois par série (réutilise un point de moins de 24 h ; protection désactivée ou échec → l'utilisateur doit confirmer de nouveau) → pour chaque correction : `UndoEntry` « en attente » écrite **avant** la modification → correction → « appliquée ».
4. **Journal d'annulation** (`UndoJournal`) : JSON Lines dans `%ProgramData%\PCDoc\backup` (administrateurs uniquement). Une entrée restée « en attente » (coupure) est signalée au démarrage. Page **Historique** : liste + « Annuler » (l'état actuel est vérifié avant d'annuler).
5. **Conseiller** (M2) : catalogue `PCDoc.Definitions/advisor.json` (services, tâches, programmes connus → niveau + condition). Conditions vérifiées : imprimante réelle, Bluetooth, biométrie, lecteur de carte à puce, fax, PC portable. Condition invérifiable → 🔴. Élément inconnu : programme au démarrage non Microsoft → 🟢 (désactivation réversible, comme le Gestionnaire des tâches) ; service ou tâche inconnu → 🔴 ; liste d'exclusion → 🔒.
6. **Corrections** (toutes réversibles) : désactiver/réactiver un programme au démarrage (`StartupApproved`) ; changer le démarrage d'un service (`Start`/`DelayedAutostart` sauvegardés) ; désactiver/réactiver une tâche planifiée. Chaque clé de registre touchée est exportée en `.reg` dans le dossier de sauvegarde.
7. **Bilan** : les éléments 🟢 du catalogue encore actifs deviennent des problèmes « Info » corrigeables ; « Corriger » et « Tout corriger (sûr uniquement) » actifs.
8. **Assistant de premier lancement** (dans la fenêtre) : langue, mode, protection du système (bouton « Activer » si elle est désactivée).
