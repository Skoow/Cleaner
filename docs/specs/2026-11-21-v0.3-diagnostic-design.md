# v0.3 — Diagnostic (M3), design court

Module **Diagnostic** (projet `PCDoc.Modules.Diagnostic`), page du même nom, problèmes envoyés au Bilan.

## Contenu
1. **Écrans bleus** : événements `Microsoft-Windows-WER-SystemErrorReporting` 1001 (journal Système, code d'arrêt) et `Kernel-Power` 41 (arrêt brutal, code d'arrêt éventuel) + fichiers de `%SystemRoot%\Minidump`. Code d'arrêt traduit (table des codes courants : nom + explication simple). Bilan : ≥ 1 écran bleu en 30 jours → Attention ; ≥ 3 → Critique.
2. **Plantages d'applications** : journal Application, événements 1000 (Application Error) et 1002 (Application Hang) des 30 derniers jours, regroupés par application. Bilan : une application qui plante ≥ 3 fois → Attention.
3. **Périphériques en erreur** : `Win32_PnPEntity.ConfigManagerErrorCode ≠ 0` (22 = désactivé exclu), code traduit (cause + solution). Bilan : Attention par périphérique.
4. **Santé des disques** : compteurs intégrés à Windows (`MSFT_PhysicalDisk.HealthStatus`, `MSFT_StorageReliabilityCounter` : température, usure, erreurs de lecture non corrigées). Bilan : état « Avertissement » ou usure ≥ 90 % → Attention ; « Défectueux » ou erreurs non corrigées → Critique (« sauvegardez vos fichiers »).
5. **Redémarrage en attente** : clés `Component Based Servicing\RebootPending`, `WindowsUpdate\Auto Update\RebootRequired`, `PendingFileRenameOperations`. Bilan : Info.
6. **Pilotes anciens** : `Win32_PnPSignedDriver`, pilote non Microsoft de plus de 5 ans → Info (mise à jour via le Centre de mises à jour, v0.5).
7. **Réparations en un clic** (passent par le pipeline sûr : point de restauration, Historique) : vider le cache DNS (🟢), vérifier les fichiers système SFC (🟢, long), réparer l'image Windows DISM /RestoreHealth (🟢, long, utilise Windows Update). Lancées **cachées** (`CreateNoWindow`), progression affichée dans la page. Non annulables par nature, mais sans risque : pas de confirmation renforcée.
8. **Fiche « Mon PC ne démarre plus »** dans la page (texte d'aide, aucun lien externe).

## Choix
- **Santé des disques sans smartmontools** : Windows fournit les compteurs de fiabilité ; règle de choix de la spec (aussi bien ou mieux avec ce qui existe). smartmontools pourra compléter plus tard pour les disques non pris en charge.
- **Reportés** : pilote en cause d'un écran bleu (analyse des minidumps), températures (LibreHardwareMonitor/PawnIO), assistants guidés (« Pas d'internet »…), réinitialisation réseau et réparation de Windows Update, processus gourmands.
