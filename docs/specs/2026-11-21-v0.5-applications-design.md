# v0.5 — Applications (design court)

## Contenu
1. **Inventaire** : programmes Win32 (clés Uninstall HKLM 64/32 bits et du profil cible) + applications du Store du profil cible
   (`Get-AppxPackage -User <SID>`, PowerShell caché, sortie JSON en base64) + paquets provisionnés (`Get-AppxProvisionedPackage`).
   Nom affiché du Store lu dans `AppxManifest.xml` (ressources `ms-resource:` via `SHLoadIndirectString`).
   Ignorés : composants système, mises à jour (`ParentKeyName`, `ReleaseType`), entrées sans nom.
2. **Niveaux de risque** : 🔒 paquets système / frameworks / non supprimables, Edge, WebView2, Store, PCDoc ;
   🔴 pilotes et runtimes (Visual C++, .NET, pilotes graphiques, audio, chipset) ; 🟢 le reste (choix de l'utilisateur) ;
   catalogue `bloatware.json` pour les applications préinstallées (🟢 ou 🟠 selon l'usage).
3. **Désinstallation** (non annulable, point de restauration avant) :
   - MSI → `msiexec /x {code} /qn /norestart` (0, 1605, 3010 = succès) ;
   - Inno Setup (`_is1`) → `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART` ; `QuietUninstallString` si fournie ;
   - sinon le désinstalleur de l'éditeur s'ouvre (exception « fenêtre unique », annoncée avant) ;
   - l'exécutable doit être dans Program Files ou Windows (dossiers réservés aux administrateurs), jamais un lien ;
   - programmes installés pour l'utilisateur seul (HKCU) : non proposés en v0.5 (il faut les lancer sans élévation).
   - Store : `Remove-AppxPackage -User <SID>` ; applications préinstallées : aussi `Remove-AppxProvisionedPackage`
     (ne reviennent pas pour les nouveaux comptes). Noms vérifiés par expression régulière avant tout appel.
4. **Restes** : après une désinstallation, si le dossier d'installation existe encore (sous Program Files, pas un dossier
   partagé par un autre programme), il est proposé en **quarantaine** : déplacé dans `%ProgramData%\PCDoc\quarantine`
   (réversible depuis l'Historique), supprimé définitivement après 7 jours.
5. **Bilan** : applications préinstallées 🟢 encore présentes → « Info » corrigeables.
6. **Page Applications** : recherche, onglets « Installées » et « Préinstallées », taille, éditeur, date, bouton « Désinstaller ».
