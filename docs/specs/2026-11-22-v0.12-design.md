# v0.12 — Effacement sécurisé, réseau, licences, rapport pour forums (design court)

1. **Effacement sécurisé** (Nettoyage, onglet) : fichiers/dossiers déposés ou saisis ; ouverture sans lien et sans partage,
   refus des liens et des liens physiques multiples, contenu écrasé par des données aléatoires (écriture directe), puis suppression
   par le même handle. Refus : Windows, Program Files, ProgramData\Microsoft, dossier de PCDoc, racine d'un disque, dossier
   Utilisateurs ou profil entier. Espace libre par `cipher /w`. 🟠, non annulable, confirmation renforcée ; limite des SSD expliquée.
2. **Réseau** (Diagnostic, onglet) : cartes actives, DNS (statiques ou du routeur), choix Cloudflare/Quad9/Google/automatique
   par netsh (réversible : anciens serveurs gardés) ; réseaux Wi-Fi enregistrés via `netsh wlan export` (XML indépendant de la
   langue, dans le dossier protégé, supprimé aussitôt), mots de passe seulement à la demande.
3. **Licences** (Système, onglet) : état d'activation de Windows/Office (5 derniers caractères), clé d'origine du micrologiciel
   (masquée jusqu'au clic).
4. **Rapport pour forums** (Bilan) : rapport copié après anonymisation (compte, PC, profil, SID, IP, MAC, courriels, numéros de série).
